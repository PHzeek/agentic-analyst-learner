# The Agentic Analyst — learner repo

Building an AI analyst that answers business questions correctly, one episode at a time, in public. The data is a synthetic online jewelry store (~6,000 orders) generated by a seeded script, so every number is reproducible.

**Season 2 of Build With Me** — by [Ezekiel Adoh](https://prolificanalytics.io), Prolific Analytics.

## Episode 1 result

"What was revenue this year?" — four valid SQL answers:

| Approach | Revenue |
|---|---|
| Every item sold | $877,454 |
| Minus test orders, staff accounts, cancellations | $758,613 |
| Minus refunds via a join (fan-out: each refund counted ~twice) | $690,711 |
| **Minus refunds counted once — the governed answer** | **$725,403** |

$186K between the highest and lowest answer. Only the last one matches the finance definition. The fan-out bug: refunds totaled $33,211, but joining them to order items turned them into $67,902 — no error, just a bigger number.

## Run it

```bash
git clone https://github.com/PHzeek/agentic-analyst-learner.git
cd agentic-analyst-learner
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python data/generate_data.py                            # builds data/store.duckdb (5,998 orders, seed 42)
python checks/ep1_check.py                              # 6/6 passed
python episodes/ep1/five_answers.py                     # prints the answers table
```

## Layout

```
data/generate_data.py      seeded synthetic store → data/store.duckdb
episodes/ep1/              lesson README, worked example, five_answers.py
checks/ep1_check.py        checks each function against known values
```
